# Astra Attack ESP

아스트라 어택 (https://astra-attack.pages.dev/) 용 ESP 오버레이 유저스크립트.
적 박스 · HP 바 · 이름 · 무기 · 거리 · 트레이서 + **맵 전체 사운드 레이더** + 라스트시스 고스트. PC + 모바일.

> **v1.3**: 박스가 이제 **게임이 실제 그리는 좌표**에 붙는다. 게임 내부 three.js 씬 그래프에서
> `player-<id>` 루트의 월드 좌표를 매 프레임 읽어 그리기 때문에, 서버 스냅샷(보간 지연 ~0.4m) 대신
> 화면 속 몸통과 1:1로 맞고 60fps로 매끄럽게 따라간다. 못 찾으면 기존 서버 좌표로 자동 폴백.
>
> **v1.4**: **피격 릴레이** 추가 — 나를 맞춘 적은 거리 제한 없이 실좌표로 뜬다.
> 서버는 피격당한 본인에게 발사자의 정확한 origin 좌표가 담긴 `shot` 메시지를 보내준다
> (72m 밖 저격 실측 확인). 주황 박스 + `HIT 이름 · 무기 · 거리 · 데미지` 로 15초간 표시된다.
> 나를 저격하는 원거리 사수는 맞는 순간 화면에 그 자리에 뜬다.
>
> **v1.5**: 화면 가장자리 **총성 방향 화살표** (맵 전역, 80m까지) + 레이더에 **실좌표 핀**
> (피격 릴레이=주황 점, 마지막 목격=보라 다이아). 총만 쏴도 80m 밖 사수의 방향·거리가
> 화면에 바로 뜬다.

## 설치 (폰 / 안드로이드)

1. **Firefox** 설치 → 설정 → 확장에서 **Tampermonkey** 설치
2. 아래 링크를 탭 → Tampermonkey 설치 화면이 뜨면 **설치** 누르면 끝

**설치 링크**
https://raw.githubusercontent.com/ad2das/astra-esp/main/astra-esp.user.js

> 아이폰은 Firefox 대신 **Userscripts** 앱(Safari 확장)에 같은 내용을 붙여넣으면 된다.

## 설치 (PC)

- Tampermonkey가 있으면 위 링크 그대로 설치
- 없으면: 게임 페이지를 열고 "처음 플레이하기" 버튼이 뜨기 전에 `F12` → Console에
  `astra-esp.user.js` 내용 전체 붙여넣기 → Enter

## 사용법

- 좌상단 **ESP** 칩 탭 = 켜기/끄기, 드래그 = 위치 이동 (위치 저장됨)
- **M** 팀원 표시 / **T** 트레이서 / **S** 내 캐릭터 / **R** 사운드 레이더 / **G** 라스트시스 고스트
- 적이 잡히면 칩 옆에 적 숫자가 뜨고, 박스 위에 이름 · 무기 · 거리, 왼쪽에 HP 바가 그려진다
- PC 키: `F6` 트레이서 / `F7` 팀원 / `F8` 마스터 / `F9` 본인 / `F10` 레이더
- 칩 아래 원형 **레이더**: 나(중앙, 위쪽 = 내 시선) 기준으로 맵 전체의 총성/폭발음을 표시
  - 반투명 부채꼴 = 방금 들린 총성의 방향·거리 판독
  - 동그란 점 = 4~6발 버스트가 들어오면 파티클 필터가 역산한 발사자 추정 위치 (몇 초 유지)

## 사운드 레이더가 뭔가

서버는 복제(약 20m) 밖의 적이라도 **모든 총성/폭발음을** `combat-sound` 이벤트로 보내준다.
이 이벤트에는 `거리(10m 단위 눈금, 5~80m)` + `좌우 음향(pan, 내 시선 기준 sin값을 0.5 단위로 양자화)`만 들어 있다.
레이더는 이 판독값을 부채꼴로 그리고, 같은 버스트의 연속 판독값을 파티클 필터로 교차시켜
발사자의 실제 위치를 수 미터 오차로 추정한다. (실측: 6발 버스트 기준 중앙값 6.6m, 77%가 8m 이내, 92%가 12m 이내)

## 참고

- 서버가 가까이 온 적만 복제해 주는 구조라 **박스는** 대략 20m 안쪽 적만 뜬다 (게임 자체가 쓰는 것과 같은 데이터)
- **피격 릴레이**만 예외로 거리 제한이 없다: 나를 맞춘 적은 70m 밖이어도 실좌표 핀이 뜬다 (`shot`의 origin)
- 서버 수신 메시지 16종을 전부 뜯어봤다: 그 외의 21m 밖 **실좌표 채널은 없다** (state/joined/킬피드/사운드/수류탄/나가기/프로필 전부 확인). 나머지 21m 밖은 고스트(마지막 목격, 15초) + 레이더(추정)로 커버한다
- 레이더는 "쏘는 적"만 잡는다 — 총을 안 쏘면 소리도 없다 (현실의 소리와 같음)
- 적/팀원 구분 없이 모든 총성이 잡히고, 단발보다 버스트(연사)에서 훨씬 정확하다
- pan 값에는 앞/뒤 거울 모호성이 있어서, 안 움직이면 앞쪽 후보와 뒤쪽 후보가 같이 뜰 수 있다 — 움직이면 곧 갈린다
- 처음에 잠깐 안 뜨면 화면을 한 번 휙 돌려보면 카메라가 잡히면서 바로 뜬다
- 업데이트: Tampermonkey가 이 파일을 주기적으로 확인해서 자동 업데이트한다
